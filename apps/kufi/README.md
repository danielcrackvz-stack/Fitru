# App Subí

Cliente Flutter del pasajero y del chofer. El nombre visible es Subí. El paquete Dart sigue siendo `kufi`.

Cómo correrla, las cuentas demo y el APK están en el [README de la raíz](../../README.md).

```bash
flutter pub get
flutter run -d chrome
flutter build apk --debug
flutter analyze
flutter test
```
